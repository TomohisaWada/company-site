# company-site

株式会社スカイラインテクノロジーズ(Skyline Technologies)のコーポレートサイトです。
事業内容、会社概要、沿革、採用情報、お問い合わせ導線などを1枚の静的HTMLページ(`index.html`)にまとめています。

## 概要

- サイト名: 株式会社スカイラインテクノロジーズ
- 内容: 事業内容 / 数字で見るスカイライン / 会社概要 / 沿革 / 採用情報 / お問い合わせ
- 構成: 単一の静的HTMLファイル(外部ライブラリ不要、Google Fontsのみ読み込み)

## ブラウザで開く手順

サーバーは不要です。以下のいずれかの方法で `index.html` を直接ブラウザで開いてください。

1. エクスプローラーで `index.html` をダブルクリックする
2. または、任意のブラウザにファイルをドラッグ&ドロップする
3. または、ターミナルから以下のコマンドを実行する

   ```bash
   start index.html
   ```
